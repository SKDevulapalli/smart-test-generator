API Reference

Integrate Kade Test Gen into your CI/CD pipeline

Service Status: Operational All systems running normally

Overview

The Kade Test Gen API allows you to programmatically generate test automation code. All endpoints accept JSON or multipart form data and return JSON responses.

Base URL: http://localhost:8081

Endpoints

GET /api/health

Check service health and get version information.

Response 200 OK
{
  "status": "UP",
  "service": "Kade Test Gen",
  "version": "1.0.0",
  "frameworks": {
    "selenium": "4.16.1",
    "restAssured": "5.4.0"
  }
}
POST /api/generate/document

Generate test code from an uploaded Word document (.docx, .doc, .txt).

Parameters (multipart/form-data)
Name Type Required Description
file file Required Word document with test requirements
testType string Required UI, API, or MOBILE
basePackage string Optional Java package name (default: com.enterprise.tests)
testCategory string Optional smoke, regression, negative, boundary, security
coverageLevel integer Optional 1-5 (minimal to extensive)
waitStrategy string Optional implicit, explicit, smart
POST /api/generate/github

Generate test code from a GitHub repository containing requirement documents.

Parameters (multipart/form-data)
Name Type Required Description
repositoryUrl string Required GitHub repository URL
githubToken string Optional Personal access token for private repos
testType string Required UI, API, or MOBILE
POST /api/generate/text

Generate test code from direct text input.

Request Body (application/json)
{
  "content": "Scenario: User Login\nGiven the user is on the login page\nWhen the user enters valid credentials\nThen the user should see the dashboard",
  "testType": "UI",
  "basePackage": "com.mycompany.tests",
  "applicationUrl": "https://myapp.example.com",
  "testCategory": "smoke",
  "coverageLevel": 3,
  "assertionStrictness": "medium",
  "waitStrategy": "explicit",
  "generateNegative": true,
  "addAssertions": true,
  "handleDynamic": true,
  "generateUtilities": true
}
Response 200 OK
{
  "success": true,
  "message": "Generated 3 test artifacts",
  "totalTests": 3,
  "generationTimeMs": 245,
  "frameworkInfo": "Selenium WebDriver 4.16.1",
  "testCases": [
    {
      "testId": "TC-000-A",
      "testName": "BasePage.java",
      "testType": "UI",
      "scenarioDescription": "Base Page Object class",
      "automationCode": "package com.mycompany.tests.pages;...",
      "className": "BasePage",
      "packageName": "com.mycompany.tests.pages"
    }
  ],
  "warnings": []
}
Error Response 400 Bad Request
{
  "success": false,
  "message": "Error generating tests: Invalid content format",
  "warnings": ["Exception: IllegalArgumentException"]
}
GET /api/github/files

List requirement files in a GitHub repository.

Query Parameters
Name Type Required Description
repositoryUrl string Required GitHub repository URL
githubToken string Optional Personal access token
Response 200 OK
{
  "success": true,
  "files": [
    "docs/requirements.md",
    "specs/login-feature.docx",
    "tests/api-spec.txt"
  ]
}

Example Usage

cURL Example
curl -X POST http://localhost:8081/api/generate/text \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Scenario: Login Test\nGiven user on login page\nWhen enters credentials\nThen sees dashboard",
    "testType": "UI",
    "basePackage": "com.example.tests"
  }'
JavaScript Fetch
const response = await fetch('/api/generate/text', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    content: 'Scenario: Login Test...',
    testType: 'UI',
    basePackage: 'com.example.tests'
  })
});
const result = await response.json();
